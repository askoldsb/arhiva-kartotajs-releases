# Arhīva kārtotājs — izlaidumi

Programmas **Arhīva kārtotājs** (piļu, muižu un vietu arhīva kārtošana) izlaidumi un automātiskās
atjaunināšanas manifests. Šeit ir tikai programma, bez lietotāja datiem. Kods glabājas privātā repozitorijā.

- `latest.json` — manifests, ko programma lasa, lai piedāvātu atjauninājumu
- `releases/` — versiju arhīvi (zip)

**Pirmā uzstādīšana (Windows):** lejupielādē jaunāko zip no `releases/`, atarhivē mapē `C:\ArhivaKartotajs`
un palaid `Palaist.bat` (vajadzīgs Python 3 un `pip install pillow`). Turpmāk atjaunina pati programma.
